# LDD seed pack

An optional, factually-reduced starting org chart — LDD Holding (the company this
template was distilled from): 8 organisations, 23 people. Name, role, org,
affiliation, one neutral line — nothing else. No opinions, no strategy
commentary, no "how to work with this person" notes, no private/personal
info.

This is not wired into `/onboard` and not required. It exists so an LDD
colleague setting up their own vault doesn't have to retype the company
structure from scratch.

## Use it

Copy whichever files are relevant into your own `wiki/organisations/` and
`wiki/people/`, then edit/prune to your own needs — add your own notes, drop
people/orgs you don't deal with, correct anything stale.

## A note on care

This was hand-reduced to facts-only from a much richer source vault. If
you're going to use it, do one more read-through yourself first — sanity
check that nothing sensitive slipped through before it lands in your own
vault (which may have different readers/reviewers than the source did).
